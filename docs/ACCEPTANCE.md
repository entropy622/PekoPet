## React 主窗口迁移 · 2026-11-10

主窗口改用 Rust / Tauri 2 / React，完整复用固定版本 dsh Chat。标题栏、四个陪伴面板与聊天共用 dsh 的导航布局；Live2D 保留独立原生窗口。

- 本机独立 Build Tools 2022 / MSVC v143 / Windows SDK 完成 release 编译，冷构建 3 分 18 秒，应用改动后的增量编译 30 秒。
- Node 共 20 项验证通过，包含原有桥接与状态测试、3 项前端测试及 ZIP 状态排除／旧时间戳回归；Rust 核心 13 项通过。
- 真实 Tauri / WebView2 离屏运行检查 1120×800 与 880×680 的五个页面，检查标题栏避让、输入区可见、横向溢出与实际本机 Yumi 头像解码。
- 在隔离 DSH_HOME 中通过真实 dsh loop 检查中文与 emoji 输入、流式标记隐藏、文件 read / edit、允许一次、拒绝审批、多题选择与文本回答、停止生成。记忆新增、编辑、暂停、删除与人格保存均通过原生 RPC。
- 无头 WebKit 加载同一前端并切换聊天与人格页面，原生 IPC 使用测试代理。取得 18 张截图，JavaScript 异常为零。重连后，dsh 的临时变更摘要接口返回 404；该摘要按上游约定仅在原运行进程存活时提供，会话正文与文件结果正常保留。
- 本机检查入口为 scripts/check-ui.mjs，截图与报告位于忽略目录 work/ui-checks。测试不激活前台、不移动系统鼠标、不使用全局输入，也不打开可见桌宠或托盘。
- 本机 Yumi 大头由真实 Cubism 模型离屏渲染，作者为 Erara_艾拉拉；PNG / ICO 与作者信息保存在本机模型缓存。公开仓库保留自有回退图标。

- 当前便携目录中的实际 exe、随包 Node 和自包含 dsh / React 依赖完成同一套离屏检查。复制按钮的控制标记过滤、HTTP 外链的原生分发入口、共享配置重连后的原会话、人格及完成状态均通过；外链测试不启动外部浏览器。
- 公开源码固定在 Git；本机候选包为 `dist/PekoPet-react-windows-x64.zip`，约 289 MiB。ZIP 清单检查包含运行入口、Chat 组件与许可，排除生成的 work / runtime 状态。从 ZIP 提取的实际 exe 成功执行 Cubism 离屏大头渲染，并检查了生成图像。
- 打包支持同一候选目录中断后的 `-Resume`，依赖使用多线程复制；本机缺少 Node 许可文件时，下载对应版本的官方许可并缓存。归档回归检查确保根目录运行状态被排除，依赖内部名为 runtime 的必要资源仍保留。
