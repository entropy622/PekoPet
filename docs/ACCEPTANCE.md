## 0.2.3 · 退出生命周期

- 复现退出时的 Object has been destroyed：角色窗口销毁后，33ms 注视定时器仍访问窗口。启用真实注视并将 shutdown 请求延迟 350ms，原 0.2.2 一次退出记录三条相同主进程异常。
